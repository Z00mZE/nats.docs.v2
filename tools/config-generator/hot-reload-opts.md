# Не поддерживают перезагрузку без перезапуска

- host
- port
  - изменение на значение, отличное от `0` для случайного порта
- listen
- client_advertise
- allow_non_tls
- ocsp
- accounts
- operator
- trusted_keys
- mappings
- server_name
- server_tags
- http
- https
- http_port
- https_port
- http_base_bath
- max_connections
- max_pending
- max_subscriptions
- max_subscription_tokens
- ping_max
- no_header_support
- disable_sublist_cache
- lame_duck_duration
- lame_duck_grace_period
- prof_port
- default_js_domain
- cluster
  - host
  - port
  - закреплённые учётные записи (маршруты), если учётная запись не существует
- resolver
  - включение или отключение
- resolver_tls
- resolver_preload
- resolver_pinned_accounts
- gateways
  - изменения, не связанные с TLS
- leafnodes
  - remotes
  - users
- jetstream
  - каталог хранения, если уже включён
  - предел файлового или оперативного хранилища, если уже включён
- websocket
  - изменения, не связанные с TLS
- mqtt
  - host
  - port
  - listen
  - authorization
  - no_auth_user
  - js_domain
- no_auth_user
- system_account
  - смена `$SYS` на другое значение
  - переход от заданного значения к отключённому состоянию
- no_system_account
