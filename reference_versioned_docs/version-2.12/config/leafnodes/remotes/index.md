# remotes {#remotes}

<Reloadable state="not-reloadable" />
Список записей о серверах, к которым может подключаться клиент листового узла.


## Свойства {#properties}

| Имя | Описание | Тип | По умолчанию | Перезагрузка |
| :--- | :---------- | :--- | :------ | :--------- |
| [`url`](./url.md) | URL или список URL удалённого сервера, принимающего соединения листовых узлов. Если удалённая сторона требует аутентификацию по имени пользователя и паролю или токену, включите их в URL, например `nats-leaf://username:password@localhost:7422`. Схема URL должна быть `nats-leaf` или `ws`. | `(multiple)` | - | Нет |
| [`nkey`](./nkey.md) | Секретный seed nkey пользователя для аутентификации этого удалённого узла. | `string` | - | Нет |
| [`first_info_timeout`](./first_info_timeout.md) | Время ожидания сообщения `INFO` удалённой стороны до отказа от соединения. | `duration` | `1s` | Нет |
| [`disabled`](./disabled.md) | Оставить удалённый узел в конфигурации, не подключаясь к нему. | `boolean` | `false` | Да |
| [`isolate_leafnode_interest`](./isolate_leafnode_interest.md) | Не передавать интерес подписок, полученный от этого удалённого узла, другим листовым узлам этого сервера. | `boolean` | `false` | Нет |
| [`request_isolation`](./request_isolation.md) | Попросить удалённую сторону изолировать интерес этого соединения на своей стороне. | `boolean` | `false` | Нет |
| [`proxy`](./proxy/index.md) | Подключаться к удалённому узлу через HTTP-прокси. | `object` | - | Нет |
| [`no_randomize`](./no_randomize.md) | Если true и указано несколько URL, сначала используется первый в списке. При отключении клиента от сервера используется следующий URL по порядку. | `boolean` | - | Нет |
| [`account`](./account.md) | Имя аккаунта или открытый NKey, задающий *локальный* аккаунт для привязки к этому удалённому серверу. Весь локальный трафик этого аккаунта пересылается на удалённый сервер. | `string` | - | Нет |
| [`credentials`](./credentials.md) | Путь к файлу учётных данных. Применяется при децентрализованной аутентификации на удалённой стороне. | `string` | - | Нет |
| [`tls`](./tls/index.md) | Конфигурация TLS для подключения и аутентификации на удалённой стороне, если требуется взаимный TLS. | `object` | - | Да\* |
| [`hub`](./hub.md) |  | `boolean` | - | Нет |
| [`deny_imports`](./deny_imports.md) |  | `(multiple)` | - | Игнорируется\* |
| [`deny_exports`](./deny_exports.md) |  | `(multiple)` | - | Игнорируется\* |
| [`ws_compression`](./ws_compression.md) | Если true и используется протокол WebSocket, соединение сообщает удалённой стороне о желании использовать сжатие. | `boolean` | `false` | Нет |
| [`ws_no_masking`](./ws_no_masking.md) | Если true и используется протокол WebSocket, соединение сообщает удалённой стороне, что *не* желает маскировать исходящие кадры WebSocket. | `boolean` | `false` | Нет |
| [`jetstream_cluster_migrate`](./jetstream_cluster_migrate.md) |  | `boolean` | `true` | Нет |
| [`compression`](./compression/index.md) | Задаёт режим сжатия для исходящего соединения листового узла. При значении `on` используется `s2_auto`. | `(multiple)` | - | Да\* |

\* Ограничения перезагрузки описаны на странице параметра.
