# max_file_store {#max_file_store}

<Aliases aliases="max_file" />
<Reloadable state="not-reloadable" note="2.12/2.14: increases only. 2.11: never, while enabled." />
Максимальный размер *файлового* хранилища. По умолчанию до 1 ТБ при наличии места.


## Типы {#types}

| Тип | Описание | Варианты |
| :--- | :---------- | :------ |
| `storage` | Размер в байтах или строка с метрической единицей, например 100K, 50M, 3G или 1T. | - |
