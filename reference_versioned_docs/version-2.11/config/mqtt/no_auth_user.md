# no_auth_user {#no_auth_user}

<Reloadable state="not-reloadable" />
Если клиент MQTT не передаёт имя пользователя при подключении, это имя используется по умолчанию на этапе аутентификации. Для клиентов MQTT оно переопределяет любое значение `no_auth_user` из основного файла конфигурации. *Примечание: этот вариант несовместим с запуском сервера в режиме оператора.*


## Типы {#types}

| Тип | Описание | Варианты |
| :--- | :---------- | :------ |
| `string` | - | - |
