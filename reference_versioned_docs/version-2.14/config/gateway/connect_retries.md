# connect_retries {#connect_retries}

<Reloadable state="not-reloadable" />
Число неудачных попыток подключения, после которого сервер прекращает подключаться к обнаруженному шлюзу. По умолчанию 0: повторных попыток нет. Если параметр включён, попытки выполняются раз в секунду. К явно заданным шлюзам это не относится.

| `integer` | - | - |
