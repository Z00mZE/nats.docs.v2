# authorization {#authorization}

<Reloadable state="not-reloadable" note="Any change to gateway username, password or timeout fails the whole reload." />
Объект авторизации для шлюзов. При использовании одной пары имени пользователя и пароля он задаёт ожидаемый сервером механизм аутентификации и способ аутентификации самого сервера при подключении к обнаруженному шлюзу. Для шлюзов, явно перечисленных в gateways, эти данные не используются: их нужно включить в URL. В этом режиме используйте одинаковые учётные данные во всей системе либо явно перечислите каждый шлюз на каждом сервере. Если в объекте tls указан только verify_and_map, задайте ожидаемое имя пользователя. Сертификаты могут различаться, но должны отображаться на одно имя пользователя. Объект авторизации также поддерживает timeout; настройки users и token не поддерживаются и препятствуют запуску сервера. Блок permissions игнорируется.


## Свойства {#properties}

| Имя | Описание | Тип | По умолчанию | Перезагрузка |
| :--- | :---------- | :--- | :------ | :--------- |
| [`username`](./username.md) | Имя пользователя для аутентификации подключающегося сервера (требует `password`). | `string` | - | Нет |
| [`password`](./password.md) | Пароль для аутентификации подключающегося сервера (требует `username`). | `string` | - | Нет |
| [`default_permissions`](./default_permissions/index.md) | Разрешения по умолчанию для пользователей, если для них явно не заданы разрешения. | `object` | - | Игнорируется\* |
| [`timeout`](./timeout.md) | Максимальное время ожидания аутентификации клиента в секундах. | `float` | `1` | Нет |

\* Ограничения перезагрузки описаны на странице параметра.
