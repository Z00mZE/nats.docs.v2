# batch {#batch}

<Since version="2.12" />
<Reloadable state="not-reloadable" />
Ограничения атомарной пакетной публикации.


## Свойства {#properties}

| Имя | Описание | Тип | По умолчанию | Перезагрузка |
| :--- | :---------- | :--- | :------ | :--------- |
| [`max_msgs`](./max_msgs.md) | Допустимое число сообщений в одном пакете. | `integer` | `1000` | Нет |
| [`max_inflight_total`](./max_inflight_total.md) | Допустимое число одновременно выполняемых пакетов на сервере. | `integer` | `1000` | Нет |
| [`max_inflight_per_stream`](./max_inflight_per_stream.md) | Допустимое число одновременно выполняемых пакетов для одного потока. | `integer` | `50` | Нет |
| [`timeout`](./timeout.md) | Время хранения незавершённого пакета до его отбрасывания. | `duration` | `10s` | Нет |
