# no_auth_user {#no_auth_user}

<Reloadable state="not-reloadable" />
Если клиент WebSocket не передаёт имя пользователя при подключении, это имя используется по умолчанию на этапе аутентификации. Для клиентов WebSocket оно переопределяет любое значение `no_auth_user` из основного файла конфигурации.

Листовой узел, подключающийся по WebSocket, также использует это значение вместо параметра `no_auth_user` верхнего уровня.

*Примечание: этот вариант несовместим с запуском сервера в режиме оператора.*
