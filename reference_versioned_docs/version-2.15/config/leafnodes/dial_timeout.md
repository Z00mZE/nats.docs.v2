# dial_timeout {#dial_timeout}

<Since version="2.15" />
<Reloadable state="not-reloadable" />
Время ожидания установки TCP-соединения с удалённым сервером. Увеличьте его для каналов с высокой задержкой, где стандартного значения недостаточно для рукопожатия. Применяется ко всем удалённым узлам, кроме задающих собственный `dial_timeout`.


## Типы {#types}

| Тип | Описание | Варианты |
| :--- | :---------- | :------ |
| `duration` | Длительность в виде строки с единицами измерения, например 100ms, 10s, 5m или 2h. | - |
