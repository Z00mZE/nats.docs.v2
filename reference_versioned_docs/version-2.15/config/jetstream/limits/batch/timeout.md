# timeout {#timeout}

<Reloadable state="reloadable" note="Enforced when a batch publish starts, so a batch already in progress keeps the timeout it started with." />
Время хранения незавершённого пакета до его отбрасывания.


## Типы {#types}

| Тип | Описание | Варианты |
| :--- | :---------- | :------ |
| `duration` | Длительность в виде строки с единицами измерения, например 100ms, 10s, 5m или 2h. | - |
