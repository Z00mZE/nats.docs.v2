# cluster {#cluster}

<Reloadable state="reloadable" note="Most cluster settings reload, including routes, name, advertise and pool_size. Changing the cluster `host`, `port` or `listen` fails the reload." />
Конфигурация объединения серверов в кластер.


## Свойства {#properties}

| Имя | Описание | Тип | По умолчанию | Перезагрузка |
| :--- | :---------- | :--- | :------ | :--------- |
| [`name`](./name.md) | Имя кластера. | `string` | - | Да |
| [`host`](./host.md) | Хост для маршрутных соединений кластера. | `string` | `0.0.0.0` | Нет |
| [`port`](./port.md) | Порт маршрутных соединений кластера. | `integer` | `6222` | Нет |
| [`listen`](./listen.md) |  | `string` | - | Нет\* |
| [`tls`](./tls/index.md) | Конфигурация TLS для защиты соединений кластера. `verify` всегда включён, а `cert_file` используется и клиентом, и сервером для взаимного TLS. | `object` | - | Да\* |
| [`advertise`](./advertise.md) | Объявляемый адрес кластера `<host>:<port>`. Полезен для кластеров за NAT. При использовании TLS этот параметр задаёт имя хоста, которое будет использоваться при обнаружении маршрута, чтобы проверка имени в TLS не завершилась ошибкой. | `string` | - | Да |
| [`no_advertise`](./no_advertise.md) | Если true, сервер не отправляет и не распространяет свои клиентские URL другим серверам кластера и не сообщает клиентам клиентские URL других серверов. | `boolean` | - | Да |
| [`routes`](./routes.md) | Список URL серверов для объединения в кластер. Маршруты к самому себе игнорируются. Если требуется аутентификация по токену или имени пользователя и паролю, укажите их в URL. | `string` | - | Да\* |
| [`connect_retries`](./connect_retries.md) | Число неудачных попыток подключения, после которого сервер прекращает подключаться к *обнаруженному* маршруту. По умолчанию 0: повторных попыток нет. Если параметр включён, попытки выполняются раз в секунду. К явно заданным маршрутам это не относится. | `integer` | `0` | Да\* |
| [`authorization`](./authorization/index.md) | Объект авторизации для настройки маршрутов кластера. При использовании одной пары имени пользователя и пароля он задаёт ожидаемый сервером механизм аутентификации и способ аутентификации самого сервера при подключении к обнаруженному маршруту. Для маршрутов, явно перечисленных в routes, эти данные не используются: их нужно включить в URL. В этом режиме используйте одинаковые учётные данные во всей системе либо явно перечислите каждый маршрут на каждом сервере. Если в объекте `tls` указан только `verify_and_map`, задайте ожидаемое имя пользователя. Сертификаты могут различаться, но должны отображаться на один `username`. Объект авторизации также поддерживает timeout; настройки users и token не поддерживаются и препятствуют запуску сервера. Блок `permissions` игнорируется. | `object` | - | Да\* |
| [`permissions`](./permissions/index.md) | Разрешения на субъекты для маршрутов, ограничивающие экспорт из этого кластера и импорт из соседних кластеров. | `object` | - | Да |
| [`ping_interval`](./ping_interval.md) | Интервал отправки ping неактивному маршруту. | `duration` | `2m` | Да |
| [`ping_max`](./ping_max.md) | Число ping без ответа до закрытия маршрута. | `integer` | `2` | Да |
| [`connect_backoff`](./connect_backoff.md) | Увеличивать интервалы между попытками переподключения маршрутов вместо повторов с фиксированным интервалом. | `boolean` | `false` | Да |
| [`write_deadline`](./write_deadline.md) | Допустимое время блокировки записи в маршрут, после которого соединение считается зависшим. | `duration` | `10s` | Да |
| [`write_timeout`](./write_timeout.md) | Действие при превышении `write_deadline` маршрута. | `string` | `default` | Да |
| [`pool_size`](./pool_size.md) | Размер пула соединений для распределения нагрузки между незакреплёнными аккаунтами. | `integer` | `3` | Да |
| [`accounts`](./accounts.md) | Список *закреплённых* аккаунтов: каждый получает отдельное маршрутное соединение между серверами. Эти соединения не занимают места в пуле. | `string` | - | Да\* |
| [`compression`](./compression/index.md) | Задаёт режим сжатия между маршрутами. При значении `on` используется сжатие `s2_fast`. | `(multiple)` | - | Да |

\* Ограничения перезагрузки описаны на странице параметра.
